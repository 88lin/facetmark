# W4 续：意图抽取是不是只在"页面自己说不清自己"的时候有用（协议先行）

`docs/w4-intent-read.md` 判了意图抽取整体不成立（50 条里"会"占 38%，预注册线是
50%）。但它在结果一节留下了一个没验的观察：**19 条判"会"的里有 11 条，页面标题本身
不携带信息**（Demo / 维基百科 / 介绍文章 / 一篇解读 / Substack 周刊 / 一个老外的观点 /
themessenger.com / diagrams.net / Calibre / GPTAnywhere / 1-800-ChatGPT）。

由此得到一条可证伪的假设：

> **H：意图抽取不是一个检索面，而是一个标题修复手段。** 页面自己把自己说清楚的时候，
> 意图只是标题的复述，加进检索只会稀释内容面；只有在页面说不清自己的时候，意图才补上了
> 内容面缺的那部分。

这一页按 W4 的规矩来：**协议在看任何结果之前写完并单独提交推送**，结果之后追加。这次
和 W4 不同的是，协议提交与结果提交是两次推送，`git log` 的先后是可以被外部验证的，不
再只能凭作者自述。

脚本：`scripts/intent_strata.py`。三个分析都只用已经存在的数据，不需要新查询集、不需要
起模型。

---

## 1. 协议（在读任何结果之前固定）

### 1.1 分层判据

两个维度，都在看结果之前定死，理由写在这里而不是脚本注释里：

| 判据 | 定义 | 为什么是这个数 |
|---|---|---|
| **标题退化** | 标题的信息词 ≤ **3** 个 | 信息词 = jieba 切分后去掉纯标点的 token。三个词以下的标题没有能力在 2,376 页的库里指认一页 |
| **正文贫瘠** | `content.char_count` < **500** | 500 字符以下，内容向量基本只吃到标题，内容面在这一页上等于没有输入 |

**样本量是在看结果之前查的，判据是按功效选的，不是按结果选的。** 查到的分布：

- 全库 2,376 页：标题退化 1,080 页（45.5%），正文贫瘠 730 页（30.7%）。
- W1 的 479 条查询：落在标题退化层的 213 条、正常层 266 条；落在正文贫瘠层的
  **0 条**。

最后这个 0 是本页第一个结论，而且它不是靠这次分析算出来的偏差，是查询集的构造决定的：
查询要从页面正文里生成，没有正文的页面就造不出查询。**因此 H 里"正文贫瘠"这一半，
W1 的查询集在结构上无法检验**，只能用非检索的代理指标（下面的 S2、S3）旁证。

### 1.2 S1 —— 检索分层（主分析，唯一定判定的一节）

- 数据：`eval_loo.json` 的逐查询结果，配置 **A**（只有内容面）与 **C_nolex**
  （内容面 + 意图面）。这两档只差一个意图面，是能拿到的最干净的对照。
- 指标：Recall@5（`rank` 为 1-based，0 表示未命中）。
- 每层各算 A → C_nolex 的配对差、bootstrap 95% CI（10,000 次重采样，种子 20260803）、
  McNemar 精确二项检验。
- 交互项 = 退化层的差 − 正常层的差，CI 由两层各自独立重采样得到。
- 混杂控制：`q_content` / `q_vague` / `q_episodic` 三类查询上意图面的行为差别很大，
  两层的类型构成不一定相同，所以逐类型再报一次分层差。

### 1.3 S2 —— 邻域分层（机制前提，不定判定）

H 成立的前提是"意图在这些页面上携带了内容面没有的信息"。用 `scripts/facet_overlap.py`
已经跑出的全库 2,376 个探针，按同样两个维度分层，看：

- 意图面 top-10 与内容面 top-10 的重合度（全库均值 26.94%）；
- 词面 `lex_seg` 对内容面的同一重合度，作为"另一个面能有多不一样"的参照；
- 意图面能否找回探针自己（`self_rank_intent`）。

如果 H 成立，退化/贫瘠层的重合度应当明显更低（意图确实说了别的），并且意图面仍能找回
自己（说的还是这一页的事）。**两者缺一，H 的机制前提就不成立。**

### 1.4 S3 —— 意图的词面接地率（反向证据，不定判定）

对全部 9,475 条 `kept = 1` 的意图，算它的信息词里有多大比例在这一页上**根本不出现**
（标题与正文都没有）。这是词面比对，改写和同义词会被算成"不接地"，所以它是**编造率的
上界，不是编造率**。按同样两个维度分层。

方向性判据：如果贫瘠/退化页面上的"不接地"比例更高，那么 H 的救援叙事就反过来了——
页面越说不清自己，模型越是在编，而不是越在补。

### 1.5 判定规则（看结果之前写死）

只有 S1 定判定，只看主判据（标题退化 ≤ 3 词）：

- **支持 H**：退化层的 C_nolex − A 差为正且 95% CI 下界 > 0，**并且**交互项 CI 下界 > 0。
- **不支持 H**：退化层的差为负，或其 CI 含 0。
- 只有一半成立（比如退化层不再显著为负、但交互项 CI 含 0）→ 记为**方向性证据**，
  不足以改默认配置，也不足以复活意图面。

无论哪个结果，**都不改任何默认值**。`FULL` 目前就只开内容面，这一页不会去动它。

### 1.6 这一节的偏差方向

三条，都对结论的可信度有影响，写在结果前面：

1. **`q_vague` 与 `intent_query` 同源。** 两者是同一个 3B 模型对同一页正文的两次生成，
   用词风格相近。这个偏差**利好意图面**。因此意图面若在这里赢了，要打折；若输了，
   是更硬的证据。（这同时更正了 `docs/w4-intent-read.md` §1.5 原先"查询集从
   `intent_query` 派生"的说法——查过生成脚本，没有记录级泄漏。）
2. **正文贫瘠层在检索上无样本。** H 的一半不可检验，S2 与 S3 只是代理。
3. **标题退化是用分词器定义的，不是用"人读了觉得没信息"定义的。** W4 那 11 条里，
   `Calibre`、`GPTAnywhere`、`themessenger.com` 这类单词标题在分词器眼里只有 1 个 token
   （落进退化层），但它们对检索其实很有判别力——用户搜 "Calibre" 一击即中。所以这个
   判据抓的是"标题短"，不完全等于 W4 人工判读时说的"标题不告诉我这页在讲什么"。
   两者不是同一个概念，不要互相引用。
