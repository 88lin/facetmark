## 思考模式与自动检测 Agent

默认是沿用服务或客户端，不能把未配置档位解释为“关闭思考”。接口是否支持思考、
可选档位和账户权限是不同问题，仍以所选模型的连接测试为准。

| 连接 | 默认来源与显式选择 |
| --- | --- |
| OpenAI 兼容接口 | 不设参数时沿用服务默认；控件支持 `reasoning_effort`、`thinking`、`enable_thinking`、`chat_template_kwargs`，保留无关高级参数。模型 / 地址用于建议格式，自定义中转仍需测试。 |
| Codex | 读取当前用户 / profile 的模型与 effort，以及适用的 managed new-thread 默认；目录提供默认值和可选 levels。显式选择传 `model_reasoning_effort`；`model_reasoning_summary="none"` 只隐藏思考摘要。 |
| Claude Code | 读取环境、用户设置及模型的 effort，环境优先于模型，模型设置优先于客户端通用设置。显式选择传 `--effort`，只更新子进程环境，不修改父进程或用户配置。 |
| OpenCode | 读取模型配置和 verbose 目录的变体，去掉被禁用的变体。显式选择传 `--variant`，没有目录信息时可以填写已有变体名。 |

每个 Agent 的模型 / 思考草稿分别保留，检测晚响应不能覆盖手动编辑；切换检测结果
时旧测试成功状态失效。模型、思考选择或继承配置变化都进入测试指纹。
不支持的档位或旧 CLI 能力会通过测试失败给出说明，不宣称检测到安装就能使用模型。
真实安装版本的 OpenCode verbose 输出和各模型生成质量尚未验证。
`scripts/check_opencode.py` 已增加真实目录、禁用变体过滤、默认 effort 和显式变体
到 HTTP 请求的检查，随体验工作流在 Ubuntu / Windows 的隔离服务中运行。
