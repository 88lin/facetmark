# Facetmark 桌面预览

测试分支：`desktop/facetmark-experience`。首次目标为 Windows 10/11 x64。
这是未签名预览版，不是正式发布。测试分支不会自动合并 main。

## 下载与首次使用

1. 打开 [desktop-preview Actions](https://github.com/88lin/facetmark/actions/workflows/desktop.yml)，
   选择此测试分支最新成功的运行，下载 `facetmark-windows-x64-preview`。
2. 解压后运行 NSIS 安装程序。安装到当前用户目录；带 Python 后端和 WebView2
   离线安装器，不需要安装 Python、Node、Rust，也不带大模型。
3. 导入 HTML／JSON 书签副本；或主动查找本机 Chromium 来源，再选择一个来源。
   不修改浏览器原文件，不自动读取所有个人配置。
4. 导入后即可使用默认关键词检索，点击收藏标题或外链图标打开原网页；**预览**用于检查已保存内容。
   导入失败后可重新选择同一文件重试；成功后点击 **查看已导入的收藏** 返回书库。
5. 需要摘要时，在 **设置 → AI 连接** 中选择 **本机 Agent · 使用已有登录**或 **API 服务**。
   前者检测已安装的 Codex／Claude Code／OpenCode CLI，显示实际选中的程序并复用登录与服务配置；后者填写聊天服务地址、Key 和模型名。安装或更新 CLI 后可重新检测，详情见[本机 Agent 连接](local-agents.md)。
   Ollama 等已有本机服务可填写 `http://127.0.0.1:11434/v1` 并勾选免 Key。点击 **测试并保存**，
   确认当前保存的聊天连接可用，再从收藏页展开 **显示与摘要**，选择范围并核对处理数量及发送确认。
   默认跳过已完成且未变化的内容；需要重新生成时勾选 **重新处理已完成的内容**，确认数量和说明更新后再开始。
6. 需要可选语义检索时，再填写并测试向量通道；它可以与聊天通道使用不同服务。
   测试发送固定测试句并报告实测向量维度。保存后应用已测试的向量配置；更换向量空间时确认备份与重建。
   在任务页了解发送内容并确认完整索引，完成后可主动切换检索方式。

API Key 留空且未编辑时保留；“清除已保存的密钥”才清除。更换地址不会继承
另一服务的密钥。受环境变量控制的字段显示只读。保存与应用是不同状态；向量
配置应用前旧空间仍保持一致。检测到 CLI 不代表登录或调用成功，摘要仍使用该 Agent 的模型服务。
**测试连接**只测试当前填写的通道，**测试并保存**在成功后保存该通道。摘要任务只要求当前保存的聊天连接测试通过；
聊天保存成功会提示可以生成摘要，向量保存成功会提示继续应用有变更的向量配置。
完整索引要求聊天与向量两条连接均通过。后台重启后，开始或继续模型任务前需要重新测试相应连接。

## 日常操作

- 收藏页可新增网址、直接编辑、批量管理、整理文件夹与标签、导出 JSON／HTML；显式打开预览后还可
  删除及单独提取正文或生成摘要。具体范围、确认和导入边界见
  [收藏管理、阅读处理与设备同步](library-management.md)。
- 设置分为 **AI 连接、设备同步、浏览器扩展、桌面与更新**；在这些分类之间切换会保留未保存的表单。
  **设备同步**支持共享文件夹同步：先预览、解决冲突并确认，再按需开启自动模式。
  只同步书签信息，正文、摘要、模型密钥及原始数据库不参与同步。
- 顶部切换收藏与浏览批次；桌面收藏页用可搜索、可纵向滚动的文件夹／标签／站点目录，窄窗口从筛选中进入。
- 标题和外链图标直接打开原网页；勾选框用于选择，**预览**按钮才使列表收成紧凑索引，显示正文、AI 摘要和相关书签。
  收藏底部的铅笔按钮可直接编辑。桌面和窄窗口阅读器均提供 **返回收藏**，保留查询与浏览位置。
  专注阅读扩大正文空间，有多个真实章节时显示目录。未保存正文与未生成摘要会明确说明。
- 卡片和列表直接显示多行摘要或正文摘录，手机列表同样可见；实际裁切时出现 **展开全文**。
  常驻状态行提供 **全部／待生成／有摘要／失败**及数量，排序菜单直接可见，**显示与摘要**收纳内容切换和摘要处理范围。
  有查询的语义检索结果会隐藏这组工具；要按全部匹配范围处理摘要，请切回默认的关键词方式。
- **批量管理**或已有选择时，**摘要批量选择**组提供 **全选 N 条用于摘要**，选中后明确显示 **摘要处理 · 跨页生效**，可排除个别收藏后生成所选摘要。
  移动、删改标签、删除与导出仍使用各自的明确选择／页面／分类／书库范围，不使用跨页摘要选择及其排除项。
  界面逐条和本页选择上限为 1000 条；按服务端筛选范围处理不受这个总量上限限制。
- `Ctrl+K` 聚焦搜索，上下箭头在相邻勾选框或预览按钮间移动焦点，`Escape` 关闭预览而保留查询。
- 查询语法建议读取当前书库中的字段值，支持方向键选择、Enter 插入与 Escape 返回。
  综合回答位于结果上方，确认后发送问题和
  最多 8 条来源摘要；编号引用可在预览中核对，摘录降级和证据局限会明确显示。
- 窄窗口与手机 Web 用显式打开的预览抽屉，退出后焦点回到触发预览的控件。
- 任务跨页面继续；独立正文／摘要任务使用已保存的目标快照与小批次，并显示已处理／总数、失败数和暂停状态。
  **暂停**在当前批次结束后生效，可从收藏任务条或任务页继续；重启后任务页仍可找到可继续的任务。
  任务页将当前状态、进度及暂停／继续／取消放在新任务入口前面；暂停时明确显示进度已保存，完成、失败和取消各有对应说明。
  空闲时只显示处理入口；需要语义检索时展开 **建立完整索引**。开始后才显示阶段与取消操作，阶段数不当作工作百分比；独立正文不要求模型，摘要只要求聊天模型。
  默认跳过已完成且未变化的内容；重处理勾选会同时更新待处理数量与说明，取消勾选恢复跳过，0 条时不能启动。
  已验证的合成例子是 **0 → 1892 → 0**。摘要失败项可按状态范围或单条重试；正文抓取失败应继续已保存的任务或再次抓取。
- 关闭主窗口后留在托盘，首次有提示。托盘管理开机启动（默认关闭）、全局快捷键
  `Ctrl+Shift+Space` 和退出。设置中可主动检查 GitHub 正式版本与打开测试包下载页。
- 默认端口 8787 被占用时自动换端口。扩展设置使用工作台复制的当前地址和配对令牌。
  扩展需要手动加载，不会自动安装；近期已连接状态来自认证过的扩展请求。

## 数据与更新

每个数据目录有独立桌面单实例命名空间，最多一个受管后端。复用已有服务时核对版本、认证和数据库身份。
数据目录沿用 `FACETMARK_DATA_DIR`；默认使用系统用户数据目录。
应用升级前使用 SQLite backup API 备份；更换向量模型或端点前也先备份。
清理向量不删除书签与原文。卸载默认保留数据。

预览包尚未配置签名证书，不承诺消除 SmartScreen。下载和安装更新由用户主动完成。

## Web、Python 与 Docker

开发源位于 `frontend/`，构建产物为 `src/facetmark/web/dist/`，不提交生成的 JS/CSS。
Actions、Docker 多阶段构建和 Python 发布工作流先执行 `npm ci && npm run build`，
再构建完整发行物。Hatch 把生成资源纳入 wheel 与 sdist；云端检查实际 wheel 内容。
源码未构建 React 时仍可运行旧资源作开发兼容，预览发行物必须通过 React 资源门禁。

Python 方式仍为 `facetmark serve`，桌面也访问同一后端 `/app`。配对令牌仅自动
提供给 loopback Host + loopback peer；其他访问需主动输入令牌，管理接口仍限制
loopback。Docker 运行在非 root 用户下，只读根文件系统，数据卷独立持久化。
