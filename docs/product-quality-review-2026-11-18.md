## 已写入的修复与回归范围

- `navigation.ts` 统一七个页面与五个设置分类的 hash。导航、刷新、浏览器前进/后退共享同一映射；地址只含页面和分类，不写入连接草稿或凭证。
- 设置在首次访问后保持挂载，分类按首次访问延迟挂载。模型草稿和本次测试结果由原表单持有；返回时只读取当前已保存值。旧读取有序列保护，不重置草稿、不重复初始 Agent 建议或发起测试。
- 隐藏的同步、扩展与 MCP 面板停止状态轮询；已提交同步操作仍能接收结果并保持恢复状态。未访问 AI 分类时不初始化模型表单。
- 最终源码复核又确认一个同步 P2：首次状态读取已完成、原预览读取仍等待时离开，再返回会跳过预览恢复并停留在加载中。恢复逻辑改为核对原预览是否仍未读入；中止后返回继续读取，读取完成结束加载，并在成功与失败响应后核对原预览 ID，避免旧响应恢复已被编辑清除的预览或显示过时错误。两项重点回归分别阻塞首个预览响应后 Ctrl+K 离开再返回，以及编辑文件夹清除预览后让旧响应返回 410；核对自动恢复、无同步写入、新草稿保留和无过时错误。运行结果仍以最终 Actions 为准。
- Ctrl+K 显式关闭阅读层并返回收藏，抽屉和阅读关闭逻辑共同尊重搜索焦点。正常品牌链接导航保留表单；修饰键点击保留原生链接行为。
- 收藏、阅读、导入和聊天样式由对应组件文件拥有。标签使用实际宽度裁切判断，避免按字符数漏掉中文宽字符；窄屏未展开标签保持单行、默认两个标签加剩余数量，桌面保留三个，实际裁切也保留显式全标签按钮，展开显示完整内容。标签按自身高度居中，按钮保留触达范围。完整标签、标题和网址均有显式入口；窄屏摘要状态使用短文字给同列标签留空间，完整名称仍可访问。阅读概览的动作组允许换行，空笔记入口通过组件自身的 Portal 并入阅读工具栏；编辑、已有笔记、草稿和恢复状态仍在原阅读区。紧凑计数只保留一份完整可访问状态文本，短数字由其 aria-hidden 子元素的 CSS 呈现。
- `product-quality.spec.ts` 增加路由历史、无写入/无测试的合成连接草稿、品牌返回、320/390 中英深浅主题、菜单 Space/Esc、五类可见、延迟初始化、空笔记/原文导航/草稿、320px 中英阅读动作，以及多标签/宽字符标签检查。现有导入长内容矩阵和聊天短窗矩阵增加对应空间与键盘断言；已有连接重试用例补充测试成功→回收藏→返回保存，核对草稿、测试结果与无需重复测试。
