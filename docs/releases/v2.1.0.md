# Facetmark 2.1.0 · Windows 桌面与 AI 收藏工作区

本版提供可直接安装的 Windows x64 桌面应用，把收藏、阅读、AI 摘要、对话和 MCP
放在同一工作区。安装包包含 Python 后端和 WebView2 离线运行库，无需另外安装
Python 或 Node.js。使用模型接口或本机 Agent 时，仍需在设置中配置并测试连接。

## 下载与安装

- Windows：下载附件 `facetmark-2.1.0-windows-x64-setup.exe` 并运行。
- 浏览器扩展：解压 `facetmark-extension-2.1.0.zip`，在 Chromium 浏览器的扩展管理页
  开启开发者模式，选择“加载已解压的扩展程序”，再按应用内指引配对。
- Python：提供 `facetmark-2.1.0-py3-none-any.whl` 和 `facetmark-2.1.0.tar.gz`，
  保留原有 CLI/API 使用方式。安装命令可直接指向下载的 wheel。
- `SHA256SUMS.txt` 用于校验附件；`release-manifest.json` 记录源码版本、构建和验证。

## 本版变化

- 收藏工作区提供多级文件夹、跨页选择、搜索、紧凑列表和统一阅读；取消站点分类。
- AI 同时生成目标语言的标题、摘要和要点；正文与概览同页，内置提示词可编辑、恢复。
  全选与生成按钮留在原工具栏，选中项直接重做，失败保留此前阅读内容。
- 模型及自动检测的 Codex、Claude Code、OpenCode 可查看和调整思考档位。
  默认继承服务或客户端配置，修改后通过连接测试确认实际支持。
- 持久 AI 对话支持整库、单篇或最多 12 篇所选收藏，带来源引用、停止、重试和
  保留旧答案的重新回答。
- 桌面设置可启用独立令牌的 HTTP MCP，复制客户端配置，给外部 AI 检索、阅读和
  保存收藏；原 stdio MCP 保留，共 9 个工具和 3 类资源。
- 并发和限速可配置：摘要默认 4、Agent 2、对话 2、抓取 30、同站点 2；Agent 摘要
  取摘要和 Agent 两个上限的较小值。HTTP 默认 3 次尝试，支持 RPM 和 Retry-After。
- 新增网站导入、详细结果、时间轴和链接健康维护；v2 完整 JSON 恢复缺失正文、
  AI 阅读内容和对话，已有本地副本优先。
- 托盘去掉外围透明玻璃和阴影，修复原生尺寸；打磨设置、阅读、目录、搜索、
  启动、快捷键和数据保留流程。

## 验证与范围

发布附件由 GitHub Actions 从同一版本构建。Windows 包完成冻结服务、真实 TCP MCP、
离线安装、WebView、托盘、窗口、热键、退出、卸载保留数据和同版本重装检查；
扩展清单、wheel、源码包与软件内置版本在上传前再次核对。

Windows 安装器当前未签名；安装实测使用隔离的 hosted Windows CI 与合成数据，
没有扩大到全部 Windows 10/11、高 DPI 或跨版本升级认证。当前聊天整条返回答案，
冻结桌面包的向量使用 HTTP 端点；进程内 SentenceTransformer 留在 Python 可选环境。
便携 JSON 不包含密钥、向量和完整配置；网站重跑按网址去重，保留已保存正文。
