# Facetmark 2.1.1 · 模型连接与收藏可用性修复

本版包含 PR #54 的修复，解决保存过的 AI 连接反复要求测试、思考档位选择不便、
全选控件不清楚，以及浏览批次长标题、窄屏和鼠标操作问题。

## 下载与安装

- Windows：下载 `facetmark-2.1.1-windows-x64-setup.exe`。已有用户先退出旧版，
  再运行新安装器。安装包包含 Python 后端和 WebView2 离线运行库，无需另装 Python 或 Node.js。
- 浏览器扩展：解压 `facetmark-extension-2.1.1.zip`，在 Chromium 扩展管理页
  加载已解压的目录，再按应用内指引配对。
- Python：提供 `facetmark-2.1.1-py3-none-any.whl` 与 `facetmark-2.1.1.tar.gz`。
- `SHA256SUMS.txt` 用于核对附件；`release-manifest.json` 记录源码提交、构建和安装验证。

## 本版修复

- **保存模型连接**：验证记录按实际连接配置复用，并保留有限历史。测试另一套草稿
  不会使已保存连接失效；重开设置无需重复选模型或测试。保存失败保留测试结果，
  重试只保存，不再次调用模型。
- **思考模式**：high、xhigh、max 提供直接入口，也可自定义。选择、测试、保存和
  实际请求使用一致参数；具体服务是否支持该档位，以连接测试结果为准。
- **模型结果解析**：忽略最终 JSON 前的完整思考块，避免把思考中的示例或草稿当作摘要。
  未完成的输出仍报错，最终 JSON 字符串内的字面思考标签不被删除。
- **全选与阅读**：现有工具栏中提供清楚的全选胶囊、数量和半选状态，支持键盘操作；
  阅读正文可独立调整字号并保存，专注阅读切换保持列表位置。
- **浏览批次**：内容行拥有独立布局，长标题可以换行；320px 窄屏仍完整显示月份日期
  和数量。普通鼠标滚轮、左右按钮、键盘与触控板均可操作日期条。
- **批次恢复**：无需配置 AI 即可按收藏元数据整理；翻页失败保留现有内容并重试原页，
  整理失败重试原操作。补齐直达、刷新和返回的路由行为。
- **聊天**：临时消息编号不再依赖毫秒时间戳，避免 React key 碰撞导致问题重复显示。

## 验证与范围

修复应用在发行前通过 CI、收藏专项、完整体验和 Windows 安装四条工作流：浏览器
矩阵 159 项通过、2 项按场景跳过，收藏专项 93 项通过，另有 20 万收藏的 API、快照
和浏览器检查。代表性截图按源码提交与哈希复核；这些结果不等于整体视觉已获得用户认可。

本发行附件从统一的 2.1.1 标签重新构建。上传草稿前核对源文件与包版本、冻结服务、
真实 TCP MCP、离线安装、WebView、原生托盘、启动重试、同版本重装和卸载保留数据。
验证使用隔离 CI 和合成数据，不代表真实模型质量，也不覆盖全部 Windows 10/11、
高 DPI 和跨版本升级环境。Windows 安装器当前未签名，可能显示 SmartScreen。

多套命名模型配置、聊天独立连接、原生 Responses/Anthropic/Gemini 端点、批量 URL 导入、
正文翻译和原生 WebDAV 仍未实现。详见
[完整功能对照](https://github.com/88lin/facetmark/blob/v2.1.1/docs/githubstarsmanager-gap-audit-2026-10-26.md) 与
[修复及验证记录](https://github.com/88lin/facetmark/blob/v2.1.1/docs/handoff-usability-2026-10-26.md)。
