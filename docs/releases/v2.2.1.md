# Facetmark 2.2.1

本版包含 v2.2.0 之后 PR #72–#81 的修复。主要改进涉及导入恢复、检索范围、连接保存、窄屏操作和 Windows 服务恢复。

## 下载与升级

- Windows 用户可下载 `facetmark-2.2.1-windows-x64-setup.exe`，正常退出旧版后运行安装器。安装包携带 Python 后端和 WebView2 离线运行库。
- Chromium 扩展提供 `facetmark-extension-2.2.1.zip`，解压后在扩展管理页加载，或者更新已有扩展的解压目录后重新加载。
- Python 提供 `facetmark-2.2.1-py3-none-any.whl` 和 `facetmark-2.2.1.tar.gz`。附件清单与校验值见 `release-manifest.json` 和 `SHA256SUMS.txt`。

## 修复与改进

- **导入和恢复。** 离开首次设置或导入页面后仍可接续原操作。按实际编码读取书签 HTML，保留中文标题和原始网址。JSON 导入保留原内容。收藏恢复窗口留出更多空间显示原内容。 [#73](https://github.com/88lin/facetmark/pull/73) · [#81](https://github.com/88lin/facetmark/pull/81)
- **检索和阅读。** 检索的两个阶段都使用精确的文件夹、标签、站点和批次筛选。综合回答使用当前页可引用的收藏，语义结果到达排序边界时给出提示。从引用返回时恢复原控件焦点。 [#72](https://github.com/88lin/facetmark/pull/72) · [#79](https://github.com/88lin/facetmark/pull/79)
- **浏览器扩展。** 快速检索和排序阶段分别处理错误，保留可用结果。可重试同一查询，长标题默认占两行，切换排序和翻页时保留键盘焦点。后备网页同步修复两阶段读取和分页。 [#75](https://github.com/88lin/facetmark/pull/75) · [#80](https://github.com/88lin/facetmark/pull/80)
- **AI 连接和工作区。** 保存前重新核对测试是否与当前配置匹配，发生变化时保留草稿。收藏卡片、筛选状态和对话阅读区经过窄屏调整，长模型名和端点可以展开核对。 [#74](https://github.com/88lin/facetmark/pull/74) · [#78](https://github.com/88lin/facetmark/pull/78) · [#81](https://github.com/88lin/facetmark/pull/81)
- **Windows 和集成。** 修复桌面服务退出超时，从快捷方式打开恢复入口后可重新读取原收藏。恢复 Karakeep 的上游接口定时检查，并合并重复界面验证。 [#76](https://github.com/88lin/facetmark/pull/76) · [#77](https://github.com/88lin/facetmark/pull/77)

## 验证范围

发行使用统一的 v2.2.1 标签。完整 CI 覆盖后端、网页、收藏、体验、浏览器扩展、容器、CLI、MCP 和 Windows 安装。发行流程另核对包版本、冻结服务、离线安装、同版重装、卸载保留数据和附件 SHA-256。对应提交和工作流记录在随包清单中。

运行验证使用隔离环境和合成数据。真实账号、个人书库、模型输出质量与不同 Windows 配置的体验取决于实际使用环境。
