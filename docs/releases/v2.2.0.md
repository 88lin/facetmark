# Facetmark 2.2.0 · 本地工作区与全端可靠性更新

本版包含 v2.1.1 之后 PR #55–#71 的已合并改动：多套命名连接、聊天独立连接、
批量网址导入、本机笔记，以及收藏、阅读、生成任务、同步、扩展、MCP 和桌面恢复修复。
产品继续按个人本地优先工具使用，关键词搜索、整理和本机笔记无需 AI。

## 下载与升级

- Windows：下载 `facetmark-2.2.0-windows-x64-setup.exe`。已有用户先正常退出旧版，
  再运行新安装器。安装包携带 Python 后端与 WebView2 离线运行库，桌面用户无需安装 Python 或 Node.js。
- 浏览器扩展：解压 `facetmark-extension-2.2.0.zip`，在 Chromium 扩展管理页面加载已解压目录，
  按应用内指引配对；已有扩展可更新加载目录后重新加载。
- Python：提供 `facetmark-2.2.0-py3-none-any.whl` 与 `facetmark-2.2.0.tar.gz`，包含共享网页资源。
- `SHA256SUMS.txt` 提供附件校验值，`release-manifest.json` 记录实际源码提交、构建与安装验证。

升级备份完成完整数据库和实际配置副本后再发布唯一名称，保留同名旧恢复文件。
跨窗口笔记编辑使用修订检查；完整 JSON 可导出笔记与已保存阅读内容。

## 新增与改进

- **多套命名连接**：保存并复用聊天、向量连接，保留独立草稿、测试结果与实际配置来源。
  对话可以选择自己的连接，保存失败重试保存，无需重复测试原有效配置。
- **批量网址导入**：粘贴多个网址后先看预览、检查去重，再执行导入。文件、网址与网站导入
  保留明确结果和历史，回应丢失后读取原已接受结果。
- **本机笔记**：独立于 AI 摘要编写，保存草稿和原回执；其他窗口修改时提示冲突。
  抓取、摘要与索引不会覆盖笔记，完整 JSON 可以携带笔记。
- **收藏和导出**：跨页选择、当前范围与全部匹配项有明确边界；大库使用服务端快照，
  失败保留原目标并重试，删除前确认。
- **生成任务**：实际任务、运行编号、目标快照和配置保留，暂停、取消、重启与显式恢复
  按原任务状态执行，不把读取失败当作任务已结束。
- **阅读与聊天**：正文、完整回答、输入草稿和原创建/发送回执可以恢复；远程失败时仍可阅读
  已保存内容，保留原文入口、引用、停止、重试和重新回答。
- **同步与维护**：共享目录保留原预览及冲突选择；设置已保存后的状态读取失败只重读。
  扩展、MCP 和链接维护保留最近成功事实、原操作回执及明确终态。
- **设置与导航**：设置和任务支持直达、刷新及浏览器前后退；分类、连接草稿与测试结果
  保留，Ctrl+K 搜索焦点与阅读菜单 Esc 行为修正。

## 界面与桌面修复

- 窄屏收藏与阅读收纳次要工具，完整标签和长文字有显式入口；空笔记不再先于正文大块占位。
- 调整聊天辅助区、设置分类和长导入内容，保留键盘操作、完整可访问名称和独立滚动。
- 修复英文大数量计数挤入分页、四位页码 `6667` 被原生微调箭头遮挡和焦点环覆盖邻近内容。
  窄窗分页保留 44px 触达范围，桌面英文 Go 最小为 32×32px。
- 托盘连续重开保持同一原生窗口；退出关闭所属服务，窗口恢复保留实际尺寸。
  服务就绪后工作区窗口失败时准确提示工作区暂时不可用，保留键盘重试与原服务退出确认。

## 验证与范围

发行使用统一的 v2.2.0 标签构建。完整 CI 覆盖后端、共享网页、收藏、完整体验、
真实 20 万条临时库、扩展、CLI、容器和 Windows 实际安装；发行流程另核对源文件与
包版本、冻结后端、真实 HTTP MCP、离线安装、原生托盘、启动恢复、同版本重装和卸载保留数据。
发布附件的实际提交、工作流和校验值以随包清单与对应 Actions 为准。

验证使用隔离合成数据，不认证真实模型回答质量、全部个人数据或所有 Windows/DPI/跨版本环境。
Windows 安装器当前未签名，可能显示 SmartScreen；安装包不包含大型 AI 模型。
冻结桌面包使用 HTTP 向量端点，Python 的进程内 SentenceTransformer 仍为可选能力。
检查通过和正式发行不表示整体视觉已经获得用户认可。
