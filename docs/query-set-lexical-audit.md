# 查询集的词面可解性审计

**状态**：协议已写，结果未跑。本文件第 2 节在看到任何数字之前提交（`git log` 可核对
先后），第 3 节在之后追加。这是 `docs/w4-intent-strata.md` 立下的规矩：预注册判据如果
和结果同一次提交，读者只能凭作者自述相信它是预注册的。

## 1 为什么问这个

`scripts/corpus/gen_queries.py` 里最长的注释都在讲防泄漏闸门：`q_content` 不许每个词都
出自标题，`q_vague` 不许和页面共享任何**稀有词**（df < 1% 的词），也不许是标题的改写。
理由写在文件开头——v1 的 `q_content` 直接抄标题，于是每个档位都 100% 命中，这一类查询
彻底不再区分任何东西。

闸门写了，**残余从来没有量过**。没人回答过这个问题：

> 这 479 条查询里，有多少条只靠词面匹配（BM25 + 分词/三元组倒排）就能把正确答案捞
> 出来，根本不需要任何向量？

这个数字直接影响 W1 报告怎么读：

- 如果 `q_content` 大部分词面可解，那么 A 档在这一类上的 0.9591（`eval_ablation.json`）
  主要不是"内容向量面很强"的证据，而是"这些查询本来就能被词匹配解掉"。**闸门只挡了
  "标题原文"这一种泄漏，挡不住"正文里的原词"**——`check_content` 明确要求用正文里的词，
  而正文也是被索引的。
- 反过来，如果词面可解率很高，A→B 的 −5.43pp（加上词面面反而变差）就更需要解释：
  目标明明是词面能找到的，把词面面加进融合却把结果弄坏了。那说明问题在**融合**（RRF
  把一个能解的列表和一个也能解的列表合成一个更差的列表），不在词面面本身。这是 W2
  "修融合"那一条唯一可以在旧查询集上做的诚实测量：它不比较任何新开关的胜负，只描述
  已有档位之间的关系。

## 2 协议（在看到结果之前写下）

### 2.1 测什么

新增一个诊断档位 `lex_only = Config("lex_only", LEXICAL_FACETS)`——只有 `lex_seg` 与
`lex_tri`，没有 `content`，没有 `intent`，不开上下文、图扩展、重排、时间衰减。
`pipeline.search()` 里向量部分由 `if config.facets & VECTOR_FACETS` 守着，所以这个档位
**一次向量都不算**，也因此不需要模型权重——这正是它现在能跑的原因。

数据与 W1 完全一致，不重新生成任何东西：

- 库快照 `library-w1-indexed.db`（2,376 页，`md5 5c3249a2b1f510a6d68af13c0763d8c3`）
- 查询集：`eval_loo.json` 里那 479 条（含 `target_id`，1-based rank，0 = 未命中）

主指标 **Recall@5**，附报 Recall@1，按 `qtype` 分。

### 2.2 预注册的判读线

| 观测 | 判读 |
|---|---|
| `q_content` 的 `lex_only` R@5 **≥ 0.60** | 这一类**大体词面可解**。W1 里 `q_content` 上的所有档位差异都要按"在一个词匹配就能解决的子集上比较语义检索"来读，报告须加限定。 |
| `q_vague` 的 `lex_only` R@5 **≥ 0.30** | `q_vague` 的防泄漏闸门**不够**。"不共享稀有词"允许常见词的组合把目标拼出来，而 C−B 这条判据完全建立在 `q_vague` 上。 |
| `q_episodic` | 不设线。闸门没针对它，时间短语是我们自己算的，词面能不能解不构成对任何判据的威胁。 |

三条线都不改任何 W1 判定，也不重开任何闸门。**这一节只能产出限定条件，不能产出新
结论**——同一批 479 条查询已经被用来提出过假设，再拿它判胜负就是循环论证。

### 2.3 互补性（同样预注册）

对每条查询，把 `lex_only` 的命中与 A 档（仅内容向量，取自 `eval_loo.json`）的命中做
四格表：

|  | A 命中 | A 未命中 |
|---|---|---|
| `lex_only` 命中 | 都能 | **只有词面能** |
| `lex_only` 未命中 | 只有向量能 | 都不能 |

"只有词面能"这一格是**融合本该赚到的钱**。A→B 是 −5.43pp，说明融合实际是亏的。两个
数字放在一起才能区分两种完全不同的病因：

- 这一格很小 → 词面面本来就没什么可贡献的，A→B 变差是它在**噪声上**盖过了内容面。
  处置是降权，也就是 `C_lowlex` 那条路。
- 这一格不小 → 词面面确实能捞到内容面捞不到的页面，是 **RRF 把它们合坏了**。处置是
  改融合规则（或候选级的择一），降权只会把这一格一起扔掉。

预注册的分界：**"只有词面能"占全部查询 ≥ 5%** 就算"不小"。5% 是因为 A→B 的绝对损失是
5.43pp，同量级的收益空间才值得为它改融合。

### 2.4 明确不做的事

- 不生成新查询，不改任何闸门参数，不重新索引。
- `lex_only` 是诊断档位，**不进默认**，也不进预注册的 A–E 阶梯（放 `EXPLORATORY`）。
- 不报告任何新开关（`C_lowlex`、`D_gated`、`A_gatedctx`、`C_abstain`）在这批查询上的
  胜负。它们的动机来自这批查询，胜负必须留给新查询集。
