## 项目连续动画排查 · 从主本 7.6 迁回

**连续动画按设计路径采样：**同时观察位移、实际宽高、圆角与可见性，按控件的设计
意图规定连续范围。固定高度的共享胶囊快速反向时，应保留上一个可见帧的高度和
位置；`scale=1` 单项通过仍可能遗漏实际尺寸坍缩。动画上下文回滚时要先停止记录
绘制值，框架清理发生在 ref 断开之前或之后都需覆盖。这个方法来自 Facetmark D05
的实际帧问题与源码复现，适用于相应连续状态控件，不要求所有入场动画都保持尺寸。

几何记录显式读取数值，并让隔离模型保留真实 API 的属性特征。浏览器 `DOMRect`
的宽高是原型 getter，直接对象展开会遗漏；用普通对象模拟则可能让错误实现通过。
Facetmark 后续宽高断言检出这一独立原因，已按 getter 结构重放并修正字段复制。

隔离检查通过后仍回到真实运行采样，确认字段复制与清理防护同时生效，并分别
记录取证源码、实际帧范围和用户复评。后续仅更新说明的提交保留应用 / 取证版本
映射，不能用记录提交的新 hash 声称页面已重新渲染或运行。源码、截图和帧记录的
指纹用于核对证据对应关系，不代替视觉判断或设备性能测量。
