# 全端可靠性与体验修复

用户要求接手整个产品的排查、修复、体验打磨和回归，按模块提交 PR，通过验证后
逐个合并。定位为个人本地优先工具；提供的项目介绍仅作参考，入驻不是本轮目标。
原始基线为 main 的 v2.1.1 后续记录，源码从 `2977b3c` 开始检查。

## 验收方式

每个 PR 在同一份拟合并源码上运行 CI、收藏交互与截图、完整体验与 20 万条合成库、
Windows 打包安装。新的 Product quality gate 要求所有分发与交互检查均成功；
失败、取消、跳过均不能算通过。浏览器、构建、打包及安装不在本地执行。
证据只使用隔离合成数据；不接触真实浏览器资料，不把合成模型效果写成真实质量。

按真实用户路径检查首次启动、导入、搜索、目录、选择与管理、阅读、模型配置、
生成与任务恢复、聊天、备份同步、扩展、CLI/MCP、karakeep、原生桌面和分发。
每个问题需有源码依据、可复现条件和针对该条件的验证。排版与动效还需检查
云端渲染的明暗、中英、窄屏、短窗及键盘状态；技术通过不等于审美认可。

## 第四批 聊天回执、独立连接与阅读失败

创建对话原来只能由服务端分配 ID，成功响应丢失后前端无法读取原对话；消息的
去重还依赖会被“重试回答”覆盖的消息字段。本批保存原子创建回执与独立发送回执，
沿用客户端的冻结请求 ID、动作、语言、连接和收藏范围。删除后的创建回执保留
墓碑，迟到重试返回已删除；不同请求内容复用 ID 被拒绝。只读查询能确认某次
发送是否已被接受，另一窗口后续重试不会使原窗口永远卡在未确认状态。

每段对话可以独立选择已保存的聊天连接，后续问题保留选择，不改全局摘要连接。
缺失、未测试、验证撤销和环境变量锁定的连接明确拒绝；不会替换为其他模型。
命名连接拥有聊天专用客户端，回答结束后释放；没有可用向量时不初始化本机编码器。

输入事件立即保存草稿。本机只保留最近 24 项草稿、连接 ID、未确认操作与当前
收藏范围，过滤不支持或损坏的数据；不保存回答或密钥。创建期间输入的下一问
移交到真实对话 ID；服务端确认后只清理仍与已发送文本一致的草稿。刷新先读取
回执；继续发送是用户点击的显式操作，复用原快照，不因页面重开自动调用模型。
明确拒绝后，读取确认未接受即可恢复编辑连接；网络结果未知时保留原重试入口。

尚未配置模型时仍可写入并保留草稿，发送按实际连接状态禁用。初次与缓存对话
读取失败都有重读入口。停止、删除和历史分页使用即时锁或版本
校验；已删除对话的删除重试按成功收尾。状态区可以滚动，短窗的输入和停止按钮
继续可见。阅读页显示实际提取错误，区分没有正文和仍保留旧正文，并重试该篇收藏。

## 第五批 收藏管理、原操作恢复与导出范围

管理保存原来没有操作回执，成功响应丢失后重试可能再次修改、重复删除或覆盖
另一窗口后来保存的编辑。本批 v12 在同一事务中保存写入结果与回执；创建、
编辑、批量管理、分类整理及单条删除支持原请求 ID。相同动作和内容重放原结果，
不同内容或记录复用 ID 返回 409。已接受的操作可在任务忙碌时只读确认或重放。
创建/编辑与 FTS 回滚、重启、批量删除、分类名称重新出现及冲突均有隔离回归。

本机按独立请求键保留冻结内容、选择和确认状态。重开不会自动写入；成功回执
与随后读取失败分开，已保存操作只提供重读。控件有即时提交锁，未知结果保留
原操作，明确拒绝且回执不存在时可恢复编辑。恢复窗口保留创建、编辑、批量和

## 第七批 任务接受、原运行控制与重启恢复

任务原来依赖最新的 JSON 文件，启动成功响应丢失后无法核对是否已接受；控制请求
也没有绑定具体运行，迟到的暂停可能作用于后来启动或继续的任务。本批 v13 保存
每次运行快照和独立操作回执。启动、原处理范围、失败项重置与回执在同一事务接受，
提交后才调度工作。每次继续任务有新的 `run_id`；暂停与取消绑定任务及运行。
相同请求优先读取已接受回执，早于忙碌、模型连接和预览变化检查；不同动作或内容
复用 ID 返回 409。读取回执不会再次调用模型，重启后的在途运行明确显示中断。

数据库保存新任务状态，旧 JSON 是兼容镜像；镜像损坏不丢已经保存的终态。升级
扫描旧任务与原编号清单的最大值，保留已经删除的编号，也保留损坏的原文件。
最终状态与处理计数清理同事务；终态保存失败报告失败并保留处理结果，仍关闭模型
资源与数据库连接。取消优先于暂停，重放旧暂停回执不会重新设置暂停标志。

前端共用即时操作锁，在写入前按独立请求键保存冻结范围、原预览和确认状态。
正常提交不闪现恢复区；未知结果、刷新后遗留请求和已接受但状态读取失败各有
对应入口。明确拒绝会被保留，回执读取失败后仍可在恢复读取时确认是否开放修改。
返回修改前再次读取原回执，防止另一窗口后来接受同一请求。已接受只重新读取，
明确的“保留已完成内容”不会在恢复时变成强制重做。任务接受及范围预览有 20 秒
等待边界。未知启动结果仍允许取消当前可见且有编号的运行，保留原未确认操作。
