# 收藏主界面交互方案

2026-10-19 用户已明确拒绝这份浅绿收藏方案。以下仅记录原型范围和技术证据，不能作为下一版的视觉依据。它未接入应用，也不是安装包。

用户要求的源码核查见 [redesign-source-audit.md](redesign-source-audit.md)。

入口：[交互原型](../frontend/design/workbench/index.html)。原型只使用六条合成收藏，
不读取浏览器资料、不连接数据库、不请求外部资源或模型。

顶部导航、搜索、全宽收藏与按需展开的目录构成新布局。深青绿主操作配合浅杏色、
雾蓝与淡紫分类面板；双色矢量图形、柔和投影、分层阅读浮层与独立控件反馈形成
工作方向。来源标识是自有字母图形，不冒充网页封面或 favicon。

已实现的原型交互：

- 中文搜索与输入法组合事件；精确目录、分类、摘要状态、排序与视图切换。
- 原生复选框选择，跨筛选保留明确的所选范围；移动端紧凑视图保留选择控件。
- 原生阅读对话框、原网页链接、章节跳转，关闭后返回触发控件。
- 亮暗切换、目录与阅读浮层进入、悬停和按压反馈、实时减少动态效果。
- 新增和移动表单展示输入及范围，不保存；摘要弹窗说明后续服务与授权流程。
- 导出仅下载明确选中的合成记录，文件不冒充应用备份；任务与设置标明待接入。

布局、组件外观与 CSS 动画归 `workbench.css`，数据、筛选状态和事件归
`workbench.js`，文档结构与对话框归 `index.html`。没有引入全局按压事件。
当前生产组件尚未迁移，因此未删除生产 CSS。迁移时必须随组件替换移除旧规则。

本地仅检查 JavaScript 语法、CSS 解析、Python 静态分析与差异。浏览器检查在
`design-directions` Actions 工作流运行，矩阵包含 1440 × 1000、1024 × 650 和
390 × 844 的亮暗状态，以及阅读、目录、选择、紧凑与空结果状态。合成输入法事件
检查不代表真实操作系统输入法验收。所有请求被限制为隔离服务的只读本地资源。

工作流产物 `facetmark-design-directions` 包含截图、真实交互录像、源码与媒体哈希、
检查记录及 `preview/`。解压后可直接打开 `preview/index.html` 体验原型。
构建、交互通过与视觉审阅分别报告；它们不代表用户已认可设计。
