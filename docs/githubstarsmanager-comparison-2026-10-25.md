## 数据与操作边界

浏览器 HTML/Chromium JSON 来源导入读取选定书签文件，再写入 Facetmark 本地库；不会回写原浏览器资料。扩展保存/Channel B、网站爬取和 Karakeep 入库会写 Facetmark 数据；扩展正文抓取还会打开真实浏览器标签，不能统称为只读导入通道。

HTTP MCP 复用原 9 工具：search_bookmarks、get_bookmark、list_sessions、get_session、find_related、synthesize、suggest_from_context、check_link_health、save_bookmark。`save_bookmark` 增改本地收藏，`check_link_health(probe=true)` 可联网并保存判定/恢复正文；其余检索/合成也可能调用已配置模型。独立 MCP token 是接入凭据，默认关闭是功能状态，均不表示工具全只读。

JSON v2 full 是可恢复的阅读/聊天副本：补齐缺失正文/派生摘要、保存 AI 标题/要点/语言/提示词标记及来源快照，按 URL 重映射聊天引用；已有本地阅读/会话不覆盖。它不包含模型密钥、向量、完整任务历史或完整数据库运维状态。共享目录同步是 metadata DAG，正文/聊天不随之同步；应用前本机数据库备份与便携 JSON 的范围不同。

本轮暂不复制 AI topics→用户 tags、全文翻译、GitHub 远端 Stars/Lists/Fork/Actions 写操作、Release/Discover/公共代码搜索/平台 feeds、WebDAV 或 Node 插件市场。通用收藏阅读与模型处理先保持可理解、可恢复的执行链；上述项目均已逐项记录，不以“类似功能已有”掩盖未实现部分。
