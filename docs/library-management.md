# 收藏管理、阅读处理与设备同步

本指南介绍共享前端中的操作入口。所有整理操作作用于 Facetmark 书库；导入来源浏览器中的原始书签不会被改写。

## 新增、编辑与删除

- 在收藏页选择 **新增收藏**，填写 `http://` 或 `https://` 网址、标题、文件夹和标签。文件夹留空表示未分类；输入标签后按 Enter 添加，标签可以包含空格或逗号。
- 打开收藏，在阅读器中选择 **编辑**；展开 **收藏信息与检索线索** 可找到 **删除收藏**。相同的规范化网址只能保存一条，重复新增会提示已有收藏。
- 修改网址会清除该条旧正文和相关索引；修改标题或文件夹会使相关 AI 结果失效，需要重新处理。仅调整标签不会要求重新生成摘要。
- 删除须勾选确认，同时移除该条在 Facetmark 中的正文和索引。当前没有撤销或回收站；重要整理前先导出副本。

Karakeep 来源或已关联 Karakeep 的收藏以 Karakeep 为准，请到 Karakeep 修改。包含这类收藏的本机批量修改、删除或分类整理会被拒绝，不会只改一半。

## 批量与分类整理

选择 **批量管理**，勾选收藏，或使用 **选择本页**，再打开 **批量操作**。可移动到文件夹、添加或移除标签、提取正文、生成摘要、删除收藏。整理一次最多选择 1000 条；正文和摘要任务一次最多选择 200 条。

**整理分类**按完整名称作用于整个书库，不局限于当前页或当前选择：

- 重命名文件夹或标签；目标名称已存在时合并到该名称。
- 移除文件夹，将使用它的收藏移到未分类。
- 移除标签，只解除标签关联，保留收藏。

分类整理需要确认。运行中的处理任务会暂时阻止收藏修改与新的同步操作；可等待任务结束，或在任务页停止后再操作。导出仍可使用。

## 导出与重新导入

点击 **导出** 或 **导出所选**，先核对范围：整个书库、当前分类筛选、当前页结果或已选择的收藏。分类筛选不包含搜索词；处于文字搜索时，使用当前页或手动选择，避免把它误当作全部搜索结果。

| 格式 | 用途与内容 | 重新导入的边界 |
| --- | --- | --- |
| JSON | 可带走的书签副本，保留分类、标签及已有的正文、摘要等阅读数据；适合存档或供其他工具读取 | Facetmark 导入器只恢复书签信息。正文、摘要和 AI 索引需重新处理，不能用它完整回滚数据库 |
| HTML | 浏览器可导入的书签文件，包含网址、标题、分类、时间和标签信息 | 不包含正文或摘要；含逗号的标签请用 JSON 保留，避免被浏览器标签格式拆开 |

JSON 中可能包含已保存的网页内容，请按内容的敏感程度保管。导出文件不包含模型密钥、登录会话或原始数据库；它与下面的共享文件夹同步、以及本机 SQLite 备份是三种不同的用途。

## 提取正文与生成摘要

可从阅读器处理单条收藏，也可从批量操作处理所选收藏。任务页提供书库范围的处理入口，并显示任务进度、失败与停止状态。

| 操作 | 需要什么 | 实际行为 |
| --- | --- | --- |
| 提取正文 | 能访问收藏网址 | 访问网页并保存正文，不调用 AI；隐私排除、访问限制或抓取失败会跳过或记录结果 |
| 生成摘要 | 已保存并测试通过的聊天模型配置，以及本次发送确认 | 将标题、网址、文件夹和已有正文发送给聊天模型；不需要向量模型，也不会先自动抓取网页 |

没有正文也可以生成摘要，阅读器会标明基于标题推断。希望摘要依据正文时，先提取正文，再生成摘要。默认跳过已完成内容；需要重抓或重算时勾选 **重新处理已完成的内容**。正文发生变化后，旧摘要可能失效。

这些独立阅读任务不会完成整套向量检索索引。需要语义检索和相关内容时，仍需按设置与任务页提示配置模型并运行完整索引。

## 设置共享文件夹同步

Facetmark 使用你自己的文件夹交换书签信息。先用 OneDrive、iCloud Drive 或其他同步工具，让各设备能够访问同一份文件夹内容；Facetmark 本身不提供云盘账号或文件传输服务。

1. 在第一台设备的 **设置 → 在设备之间同步书签** 中，填写本机已有共享文件夹的完整绝对路径。
2. 勾选 **启用共享文件夹同步**，保存设置。Facetmark 在其中创建 `.facetmark-sync` 子目录。
3. 点击 **预览同步变更**，检查发往共享文件夹和接收到本机的新增、修改、删除数量；展开详情核对具体内容。
4. 解决所有冲突，勾选 **我已核对以上变更，并确认应用**，点击 **应用本次同步**。
5. 等云盘把整个同步子目录传完，在另一台设备填写对应的本地路径，重复保存、预览和确认。各设备的路径可以不同，但文件夹内容必须对应同一份同步历史。

请选择独立的共享文档文件夹，不要选择浏览器配置目录、Facetmark 数据目录、磁盘根目录，或通过符号链接、Windows 目录联接访问的路径。正文、摘要、向量、模型配置与密钥、浏览器登录信息，以及原始 `.db` 数据库都不参与同步。

实际交换的字段只有 **网址、标题、文件夹名称、标签、收藏时间**。Karakeep 关联收藏和不支持的地址或记录会排除，预览显示排除数量；含嵌入式用户名或密码的网址也不会发送。隐私排除控制正文抓取和模型处理，并不等于自动排除该条书签的同步元数据。

## 冲突、删除与自动模式

预览有效期为 10 分钟。本机书库或共享文件夹在预览后变化时，应用会要求重新预览。数量表中的冲突尚未计入新增、修改、删除总数，需逐条核对候选内容。

- **两端都修改**：选择保留本机状态，或采用某个共享版本。共享文件夹里存在多份独立修改时，每份版本分别列出。
- **一端删除、另一端修改**：选择有内容的版本会保留或恢复它；选择“无此书签”会删除另一端的副本。共享目录保留删除记录，以便其他设备获知删除。
- **多个记录使用同一网址**：保留其中一条，对其余重复记录选择 **删除重复书签**。全部选择完成后仍需统一确认应用。

完成首次人工确认后，可以勾选 **首次确认后自动同步** 并保存。检查间隔为 30–3600 秒，默认 60 秒；只在应用运行时执行，处理任务运行期间暂缓。有冲突时暂停自动应用，等待你在设置页重新预览并选择版本。

首次确认授权自动模式之后，后续没有冲突的新增、修改和删除可以自动应用。希望每次都检查的设备，应保留手动模式。**停用同步**会保留本机收藏和共享目录中的历史；共享文件夹暂时不可用时也可以停用。

## 本机备份与异常恢复

接收新增、修改或删除之前，Facetmark 会先创建完整的本机 SQLite 备份。路径位于应用数据目录的 `backups/library-sync-*.db`，人工同步完成后会显示本次备份路径。备份可能含正文、索引和本机同步状态；它留在本机，不会写入共享文件夹。纯上传或没有内容变化的同步不会创建这份备份；普通新增、编辑、删除也不创建这类同步前备份。

遇到同步异常，先停用自动同步并保留数据，再按情况处理：

- **共享文件夹不可用或历史尚未下载完整**：等云盘完成下载，确认同一路径可用，再重新预览。
- **出现云盘冲突副本、历史文件缺失或旧提交被修改**：保留完整目录，核对云盘的文件版本与冲突副本，恢复原来的完整历史后再预览。不要直接改写或删除同步文件来消除报错。
- **需要恢复书签清单**：可从导出的 JSON 或 HTML 重新导入，再重新处理正文与 AI 数据。重新导入是导入操作，不是完整数据库回滚，也不会自动撤销共享历史中的删除。
- **需要恢复同步前的完整本机状态**：当前没有一键还原界面。数据库恢复须在应用和后台服务停止后进行，先保留现有数据目录与原始备份，并隔离共享目录访问。备份可能带有启用中的自动同步配置，确认停用后再重新连接，以免恢复的旧状态立即参与同步。不要把 `.db` 当作书签导入文件或放入共享目录。

当前同步历史上限为 **2048 个提交、总计 64 MiB、单次提交 10 MiB、累计 100000 个书签身份（包括删除记录）**。达到上限会停止新增超限提交，保留原历史；当前没有自动压缩、历史清理或迁移按钮。不要自行删除旧文件腾空间，应保留历史并规划新的同步目录。启用新目录前，需要先核对各设备书库一致，再分别重新配置和首次确认；旧目录的删除记录不会转移过去。
