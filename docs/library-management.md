# 收藏管理、阅读处理与设备同步

本指南介绍共享前端中的操作入口。所有整理操作作用于 Facetmark 书库；导入来源浏览器中的原始书签不会被改写。

这些管理入口面向本机使用：服务须启用管理 API，请求须通过配对令牌认证，且服务接收到的调用连接须来自本机回环地址。设备间同步由各设备运行的本机服务读写共享文件夹完成。

## 浏览大量收藏与分类

桌面收藏页左侧按名称列出分类，可切换文件夹、标签或站点，用普通鼠标滚轮上下浏览。
每次显示 50 个分类，底部的 **显示更多分类** 继续加载；**查找分类** 搜索整个书库的分类，
不局限于已显示的项目；输入完整名称时，精确匹配排在最前面。窄窗口通过 **筛选** 打开同样的列表。
长名称可换行，鼠标悬停也可看完整名称；也可用 Tab 移动焦点、Enter 选择。

收藏工具行可切换卡片和列表视图，显示方式会保存在本机。点击收藏标题或外链图标直接打开原网页；
标题保留浏览器链接的右键、复制地址及新标签页操作。勾选框独立选择收藏，**预览**才打开保存内容。
切换搜索或分类会回到第一页并关闭原来的预览；从预览返回仍保留浏览位置。
新范围加载期间，本页选择和导出暂不可用，
避免把旧结果当作新分类操作；加载失败时请使用列表中的 **重试**。

多页结果可在底部输入页码，按 Enter 或点击 **跳转**；页码必须在显示的范围内。
达到检索深度上限时不会提供跨越上限的跳转。当前筛选会显示类型与名称，包括 **文件夹 · 未分类**；
点击对应条件可单独移除，**清除筛选**一次移除所有分类条件并保留搜索框里的关键词。
卡片与列表使用相同的标题字号，常用文字随浏览器默认文字大小调整。

## 直接查看摘要与筛选状态

收藏页默认使用**关键词**检索，无需配置模型。配置并建立语义索引后，可主动切换到**语义检索**。
有关键词的语义结果不显示摘要状态、显示／排序和整范围批量摘要工具；需要按完整匹配范围处理时，
切回关键词模式。语义结果仍可逐条选择或处理当前页。

关键词收藏范围中的摘要状态行显示 **全部、待生成、有摘要、失败**及对应数量。切换状态会更新当前收藏范围。
排序菜单常驻，可按最近收藏、最早收藏、标题、站点排序。
展开 **显示**可切换 **摘要／原文摘录**。点击独立的 **生成摘要**，再在处理窗口选择范围、核对数量并确认发送内容。

摘要模式优先显示已有摘要，没有摘要时显示正文摘录；卡片、列表和手机列表都保留多行内容。
标签区分 **AI 摘要、标题推断、正文摘录、暂无摘要**。只有内容实际被裁切时才出现 **展开全文**，
展开后可**收起**。生成失败的收藏显示失败提示和**重试**，也可使用单条收藏的摘要按钮。

## 新增、编辑与删除

- 在收藏页选择 **新增收藏**，填写 `http://` 或 `https://` 网址、标题、文件夹和标签。当前筛选的文件夹和标签会预先填好，可在保存前修改。文件夹留空表示未分类；输入标签后按 Enter 添加，标签可以包含空格或逗号。
- 点击收藏底部的铅笔按钮可直接编辑；也可点击 **预览**，在阅读器中选择 **编辑**。展开 **收藏信息与检索线索** 可找到 **删除收藏**。取消编辑会回到原操作位置，保留搜索条件。相同的规范化网址只能保存一条，重复新增会提示已有收藏。
- 修改网址会清除该条旧正文和相关索引；修改标题或文件夹会使相关 AI 结果失效，需要重新处理。仅调整标签不会要求重新生成摘要。
- 删除须勾选确认，同时移除该条在 Facetmark 中的正文和索引。当前没有撤销或回收站；重要整理前先导出副本。

Karakeep 来源或已关联 Karakeep 的收藏以 Karakeep 为准，请到 Karakeep 修改。包含这类收藏的本机批量修改、删除或分类整理会被拒绝，不会只改一半。

## 批量与分类整理

选择 **管理收藏 → 批量管理**，勾选收藏，或使用 **选择本页**，再打开 **批量操作**。可移动到文件夹、添加或移除标签、提取正文、生成摘要、删除收藏。界面的逐条／本页选择一次最多保留 **1000 条**，这些明确选择的收藏也可以一起提取正文或生成摘要。

翻页会保留已有选择。选中本页全部收藏后，按钮变为 **取消本页选择**，只取消当前页，保留其他页的选择；
**完成选择**退出批量模式并清空选择。达到 1000 条上限时会显示提示。

在批量选择模式或已有选择时，会出现 **全选 N 条用于摘要**。这是**跨页摘要选择**：
选择组名为 **摘要批量选择**，跨页选中后显示 **摘要处理 · 跨页生效**。它按当前关键词、分类与摘要状态选择全部匹配项，翻页后仍生效；可以逐条取消少量项目，
再点击 **生成所选摘要**，或用 **清空**取消。改变关键词、分类、摘要状态或检索方式会清空选择。

跨页摘要选择不用于移动、删改标签、删除收藏或导出，也不会把逐条取消的排除项传给这些操作。
需要整理或导出具体收藏时，请重新从 **管理收藏 → 批量管理**逐条／按页选择，并核对相应窗口的范围。
大范围摘要则使用跨页摘要选择，或 **生成摘要**窗口中的范围菜单，无需每 1000 条重复操作。

**整理分类**按完整名称作用于整个书库，不局限于当前页或当前选择：

打开窗口时会预填当前文件夹名称；仅按标签筛选时会预选该标签。仍需核对名称及操作并勾选确认。

- 重命名文件夹或标签；目标名称已存在时合并到该名称。
- 移除文件夹，将使用它的收藏移到未分类。
- 移除标签，只解除标签关联，保留收藏。

分类整理需要确认。运行中的处理任务会暂时阻止收藏修改与新的同步操作；可等待任务结束，或在任务暂停／取消生效后再操作。导出仍可使用。

## 导出与重新导入

点击 **导出** 或 **导出所选**，先核对范围：整个书库、当前分类筛选、当前页结果或逐条／本页选中的收藏。分类筛选不包含搜索词和摘要状态；处于文字搜索或摘要状态筛选时，使用当前页或明确选择，避免把分类导出误当作完整结果导出。跨页摘要选择及其排除项不会改变导出范围。

默认范围跟随当前操作：有逐条／本页选择时导出所选；文字搜索时导出当前页；有分类条件时导出当前分类筛选；
没有查询和分类时导出整个书库。摘要状态和跨页摘要选择不会改变这个默认范围，下载前仍可在窗口中切换。

| 格式 | 用途与内容 | 重新导入的边界 |
| --- | --- | --- |
| JSON | 可带走的书签副本，保留分类、标签及已有的正文、摘要等阅读数据；适合存档或供其他工具读取 | Facetmark 导入器只恢复书签信息。正文、摘要和 AI 索引需重新处理，不能用它完整回滚数据库 |
| HTML | 浏览器可导入的书签文件，包含网址、标题、分类、时间和标签信息 | 不包含正文或摘要；含逗号的标签请用 JSON 保留，避免被浏览器标签格式拆开 |

JSON 中可能包含已保存的网页内容，请按内容的敏感程度保管。导出文件不包含模型密钥、登录会话或原始数据库；它与下面的共享文件夹同步、以及本机 SQLite 备份是三种不同的用途。

## 提取正文与生成摘要

收藏卡片或列表可直接生成单条摘要、重试失败项；预览中可提取正文或生成摘要，批量操作可处理明确选中的收藏。
点击收藏页 **生成摘要**，在 **摘要处理范围**中选择 **当前范围、当前未生成、当前失败重试、整个书签库**。
前三个范围保留当前关键词及分类条件；**当前未生成**和**当前失败重试**分别改用待生成或失败状态，整个书签库则清除这些筛选。
任务页也提供书库范围的正文与摘要入口。

确认窗口先计算本次符合条件的条目数，核对数量、范围与是否重新处理后再开始。默认跳过已完成且未变化的内容；
勾选 **重新处理已完成的内容**后，数量与说明同时更新，明确包括这些内容。取消勾选则恢复跳过；数量为 0 时不能开始任务。
因此，“当前筛选结果有收藏”并不等于“本次还有待处理内容”。隐私排除和不可处理项不计入待处理总数；历史合成例子的数量验证见[验证记录](desktop-validation.md)。
预览后书库若发生变化，需要关闭窗口并重新打开，取得最新范围。
摘要处理还需要勾选本次内容发送确认。

| 操作 | 需要什么 | 实际行为 |
| --- | --- | --- |
| 提取正文 | 能访问收藏网址 | 访问网页并保存正文，不调用 AI；隐私排除、访问限制或抓取失败会跳过或记录结果 |
| 生成摘要 | 已保存并测试通过的摘要来源，以及本次发送确认 | 将标题、网址、文件夹和已有正文交给所选 Agent 的模型服务或聊天 API；不需要向量模型，也不会先自动抓取网页 |

没有正文也可以生成摘要，阅读器会标明基于标题推断。希望摘要依据正文时，先提取正文，再生成摘要。默认跳过已完成且未变化的内容；需要重抓或重算时勾选 **重新处理已完成的内容**。正文发生变化后，旧摘要可能失效。

摘要来源在设置页选择：

- **本机 Agent · 使用已有登录**：检测已安装的 Codex、Claude Code 或 OpenCode CLI，显示自动模式实际选中的程序，也可指定 Agent。可在可见的模型选择器中搜索、沿用默认或手动输入；OpenCode 使用 `provider/model`。安装并登录后可点击 **重新检测**，草稿会保留。探测到的路径和超时设置在 **超时与安装位置**中查看。详见[本机 Agent 连接](local-agents.md)。
- **API 服务**：填写聊天服务地址和 API Key，在同一模型输入框直接输入，或用右侧目录按钮搜索选择；已有本机服务可按界面要求使用免 Key 设置。

检测到 CLI 不等于已登录或连接可用。**测试连接**检查当前填写的配置，**测试并保存**在测试成功后保存该通道；
聊天通道成功后提示可以开始生成摘要，向量通道成功后提示继续应用有变更的向量配置。
模型目录不证明访问权限。开始摘要前需要匹配已保存配置的成功测试。已保存的测试记录可跨后台重启保留；仅在配置／实际命令指纹变化或匹配记录缺失时，开始或继续任务前需要重新测试。

大范围任务由服务端保存目标快照并分批执行，浏览器只提交筛选条件和少量排除项，不上传整个书库的 ID 列表。
**1000 条是界面明确选择的上限，不是按范围处理的总量上限**；处理 API 的显式 ID 列表和跨页排除列表分别最多 10000 条。
源码中正文每批最多取 64 条；摘要批次按 API 并发配置控制且最多 64 条，本机 Agent 每批最多 2 条。
这些限制控制同时加载和处理的工作量。200000 条合成数据的分页、范围与目标快照基准见
[验证记录](desktop-validation.md)。这类基准不代表已向真实模型处理完 200000 条摘要，也不代表个人书库的实际速度。

收藏页任务条及任务页显示已处理／总数、失败数与 **暂停／正在暂停／继续**。暂停会等当前小批次结束，
保存已完成项目及剩余范围；重启后可在任务页找到保存的任务并继续，不会重新按当下筛选扩展目标。
失败项计入已处理数量。部分失败、暂停或中断任务从该任务继续／重试，保留已完成项目，
只重试原目标快照中的失败项并继续未完成项，不扩大到其他失败收藏。
若要另外处理当前筛选中的全部失败收藏，可新建 **当前失败重试**任务；单条 **重试**只处理对应收藏。
正文抓取失败应继续保存的任务或再次抓取，已完成且未变化的内容会跳过。
任务页先显示当前状态、进度和 **暂停／继续／取消**，随后显示新任务入口。暂停时明确提示进度已保存，
完成、失败、取消和中断分别说明结果或恢复方式。无法读取保存的任务时，可点击 **重试读取任务**。
运行中的任务不会因切换页面而中断；同一时间只执行一个处理任务。

这些独立阅读任务不会完成整套向量检索索引。需要语义检索和相关内容时，仍需按设置与任务页提示配置模型并运行完整索引。

本指南对应 `desktop/facetmark-experience` 分支的当前交互。测试提交、Actions 结果、截图来源与复核范围统一记录在
[桌面体验验证](desktop-validation.md)，避免将旧版本结果作为当前版本验收。安装包仍未签名，云端 Windows Server
检查不代替所有 Windows 10/11 真机环境；真实模型账号和服务质量需在实际连接后确认。

## 设置共享文件夹同步

Facetmark 使用你自己的文件夹交换书签信息。先用 OneDrive、iCloud Drive 或其他同步工具，让各设备能够访问同一份文件夹内容；Facetmark 本身不提供云盘账号或文件传输服务。

1. 在第一台设备的 **设置 → 设备同步** 中，填写本机已有共享文件夹的完整绝对路径。
2. 勾选 **启用共享文件夹同步**，保存设置。Facetmark 在其中创建 `.facetmark-sync` 子目录。
3. 点击 **预览同步变更**，检查发往共享文件夹和接收到本机的新增、修改、删除数量；展开详情核对具体内容。
4. 解决所有冲突，勾选 **我已核对以上变更，并确认应用**，点击 **应用本次同步**。
5. 等云盘把整个同步子目录传完，在另一台设备填写对应的本地路径，重复保存、预览和确认。各设备的路径可以不同，但文件夹内容必须对应同一份同步历史。

请选择独立的共享文档文件夹，不要选择浏览器配置目录、Facetmark 数据目录、磁盘根目录，或通过符号链接、Windows 目录联接访问的路径。正文、摘要、向量、模型配置与密钥、浏览器登录信息，以及原始 `.db` 数据库都不参与同步。

实际交换的字段只有 **网址、标题、文件夹名称、标签、收藏时间**。Karakeep 关联收藏和不支持的地址或记录会排除，预览显示排除数量；含嵌入式用户名或密码的网址也不会发送。隐私排除控制正文抓取和模型处理，并不等于自动排除该条书签的同步元数据。

## 冲突、删除与自动模式

预览有效期为 10 分钟。本机书库或共享文件夹在预览后变化时，应用会要求重新预览。数量表中的冲突尚未计入新增、修改、删除总数，需逐条核对候选内容。

- **两端都修改**：选择保留本机状态，或采用某个共享版本。共享文件夹里存在多份独立修改时，每份版本分别列出。
- **一端删除、另一端修改**：选择有内容的版本会保留或恢复它；选择“无此书签”会删除另一端的副本。共享目录保留删除记录，以便其他设备获知删除。
- **多个记录使用同一网址**：保留其中一条，对其余重复记录选择 **删除重复书签**。全部选择完成后仍需统一确认应用。

完成首次人工确认后，可以勾选 **首次确认后自动同步** 并保存。检查间隔为 30–3600 秒，默认 60 秒；只在应用运行时执行，处理任务运行期间暂缓。有冲突时暂停自动应用，等待你在设置页重新预览并选择版本。

首次确认授权自动模式之后，后续没有冲突的新增、修改和删除可以自动应用。希望每次都检查的设备，应保留手动模式。**停用同步**会保留本机收藏和共享目录中的历史；共享文件夹暂时不可用时也可以停用。

## 本机备份与异常恢复

接收新增、修改或删除之前，Facetmark 会先创建完整的本机 SQLite 备份。路径位于应用数据目录的 `backups/library-sync-*.db`，人工同步完成后会显示本次备份路径。备份可能含正文、索引和本机同步状态；它留在本机，不会写入共享文件夹。纯上传或没有内容变化的同步不会创建这份备份；普通新增、编辑、删除也不创建这类同步前备份。

遇到同步异常，先停用自动同步并保留数据，再按情况处理：

- **共享文件夹不可用或历史尚未下载完整**：等云盘完成下载，确认同一路径可用，再重新预览。
- **出现云盘冲突副本、历史文件缺失或旧提交被修改**：保留完整目录，核对云盘的文件版本与冲突副本，恢复原来的完整历史后再预览。不要直接改写或删除同步文件来消除报错。
- **需要恢复书签清单**：可从导出的 JSON 或 HTML 重新导入，再重新处理正文与 AI 数据。重新导入是导入操作，不是完整数据库回滚，也不会自动撤销共享历史中的删除。
- **需要恢复同步前的完整本机状态**：当前没有一键还原界面。数据库恢复须在应用和后台服务停止后进行，先保留现有数据目录与原始备份，并隔离共享目录访问。备份可能带有启用中的自动同步配置，确认停用后再重新连接，以免恢复的旧状态立即参与同步。不要把 `.db` 当作书签导入文件或放入共享目录。

当前同步历史上限为 **2048 个提交、总计 64 MiB、单次提交 10 MiB、累计 100000 个书签身份（包括删除记录）**。达到上限会停止新增超限提交，保留原历史；当前没有自动压缩、历史清理或迁移按钮。不要自行删除旧文件腾空间，应保留历史并规划新的同步目录。启用新目录前，需要先核对各设备书库一致，再分别重新配置和首次确认；旧目录的删除记录不会转移过去。
