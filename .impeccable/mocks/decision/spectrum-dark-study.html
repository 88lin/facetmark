创建和嵌套组件

React 应用由组件构成。组件是拥有自己的逻辑和外观的 UI（用户界面）的一部分。它可以小到一个按钮，也可以大到整个页面。

React 组件是返回标签的 JavaScript 函数：

function MyButton() { return ( <button>我是一个按钮</button> ); }
