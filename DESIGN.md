# Design System: Facetmark collection workbench

## Overview

**Creative North Star: "Collection workbench — Operate"**

Facetmark makes a large bookmark collection useful from the collection itself. Titles are native links to the original websites; independent checkboxes, readable summaries or page excerpts, status filters and scoped batch actions support browsing and processing without first opening a reader. A compact title/count, rounded search and searchable vertical category directory organize the work. The layered Facetmark mark, white cards and lake-blue interactions retain the identity.

Preview is an explicit secondary action for inspecting saved content. It retains its bounded article measure, quiet chapter rail and return context, while ordinary title activation stays with the original website and checkbox selection stays in the collection. Bundled Manrope, explicit local Chinese fallbacks with weight synthesis, relative text roles, dark-theme colors, keyboard access and reduced motion carry the system across desktop and Web.

**Key Characteristics:**

- A compact collection shell keeps direct original links, readable content and scoped actions together.
- Complete folders, tags and sites are searchable and vertically scrollable with a mouse; loading more is explicit.
- Source-first cards and a persistent list alternative share strong titles and multiline summaries or excerpts.
- Lake-blue selection, compact controls and circular icon actions clarify state and priority.
- Native links, checkboxes and optional preview buttons have separate targets and keyboard semantics.
- A compact status row keeps processing state and sorting visible; a disclosure holds display and batch-summary controls.
- Cross-page selection appears in selection mode and applies to summary processing; metadata management and export retain their own scope.
- Processing counts explain whether completed, unchanged content is skipped or included for reprocessing.
- Current task state, progress, recovery and errors precede new-work shortcuts; saved tasks can be continued.
- Changing query, category, summary status or search mode clears incompatible selections; stale results remain unavailable for scoped actions.

The user-supplied interface reference is [GithubStarsManager](https://github.com/AmintaCCCP/GithubStarsManager), inspected at `6d1dd80700b0ee717f79a5da7d0137f32afc91b7`; its compact controls and accessible category organization inform this revision. It is an interface reference, not an approved pixel comp. No reference code or screenshots ship in Facetmark.

## Colors

Frontmatter is normative. Base names map to runtime custom properties; each `-dark` token is the same semantic role in dark mode. Sidecar tonal ramps are preview swatches, not extra runtime tokens.

### Primary

- **Lake Blue** (`accent`): actions, links, selected titles, active navigation/tab text, focus and reading position.
- **Lake Mist** (`soft`): active header navigation and reader tabs, source badges, chips, notices, pressed controls and text selection.
- **Selected Water / Selected Edge** (`selected`, `selected-edge`): active index fill and border; the edge also marks card hover, folder selection and the import target.
- **On Lake Blue** (`on-accent`): text and mark strokes on filled primary actions.

### Neutral

- **Pure White** (`canvas`): header, open cards, search, reader and support surfaces; blue charcoal in dark mode.
- **Pale Blue Workspace** (`desk`): surrounding workspace, transparent index rows and focused header.
- **Cool Inset** (`inset`): navigation tray, fields, reader actions, skeletons, diagnostics and shared hover.
- **Deep Blue Ink** (`ink`): titles, prose, form input and ordinary category names.
- **Secondary Blue Ink** (`secondary-ink`): readable excerpts, category-type labels and dialog descriptions, with a corresponding dark-theme role.
- **Muted Blue Ink** (`muted`): metadata, placeholders, inactive states and secondary controls.
- **Cool Rule / Navigation Scrim** (`rule`, `overlay`): fine borders/seams and temporary navigation backdrop. The full-width reader overlay is transparent.

Error Red (`danger`) accompanies explicit failures, recovery and destructive-action warnings. Dark mode retains hierarchy with pale blue accents over deeper surfaces.
